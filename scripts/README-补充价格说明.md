## 文件说明

### 1. wind-quick-list.txt（推荐）
**最简格式**，直接复制到Wind查询框
- 84个产品名称，每行一个
- 可直接粘贴到Wind的批量查询功能

### 2. missing-products-for-wind.csv
**详细格式**，包含产品信息
- 列：产品名称 | commodityKey | 期望单位 | 优先级 | 备注
- 适合需要了解产品详情时使用

### 3. price-template.csv
**填入格式**，导出后填写价格
- 列：产品名称 | 最新价格 | 单位 | 数据来源 | 备注
- 从Wind获取价格后，填入此文件
- 完成后可直接用于更新JSON

### 4. missing-products.txt
**分组说明**，按产品类别组织
- 便于理解产品分类
- 包含commodityKey映射关系

## 使用步骤

1. **查询价格**：使用 `wind-quick-list.txt` 在Wind中批量查询
2. **导出数据**：将查询结果导出为Excel/CSV
3. **填入模板**：将价格填入 `price-template.csv`
4. **更新系统**：告诉我，我会用填好的数据更新 `price-table.json`
